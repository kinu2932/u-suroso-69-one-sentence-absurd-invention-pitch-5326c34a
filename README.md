One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a washing machine that holds one sock hostage from every load and only returns it once you apologise out loud for overloading it. It explains where the missing socks go — and ransoms them for an apology.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes one sentence (129 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Python 3.13, standard library only, deterministic.
